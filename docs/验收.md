- SEC 财务事实与申报元数据实测可用；公司目录和申报 HTML 原文在当前环境返回 403，未绕过访问限制。

## 原始文件与原生分析 Agent 验收（2026-10-14）

### 本轮实现

- 七个业务工具，新增 `fetch_filings`；原始 HTML 按内容哈希落盘，数据库保存固定版本引用，不做 HTML 解构、章节提取、全文/游标专用工具或向量检索。

- 报告收尾额外使用一次有界的无工具模型调用；每次模型和工具执行记录到同一 run。并非把所有研究文字直接当最终报告。

- Docker 默认网络和权限策略未增加额外加固。backend 挂载 Docker socket，适用于可信本地环境，不宣称生产多租户隔离。
