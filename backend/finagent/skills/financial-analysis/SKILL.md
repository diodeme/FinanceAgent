# 财务分析方法

这份方法由财务分析师维护。它指导如何研究与表达，不扩大数据权限，也不替代事实核验。用户明确的范围、语言、篇幅和格式优先于下面的默认写作习惯。

## 先确定分析对象和证据

1. 阅读当前资料清单，确认公司、报告期间、问题和已有数字/原文。区分实际财季与自然季度、当季与年初累计、时点余额与期间流量，以及货币、百万/十亿等单位。
2. 结构化数据用于核对数值、趋势、比率和计算血缘；财报原文用于解释业务驱动、会计口径、管理层判断与风险。综合分析应把两者联系起来，而不是分别复述两份资料。
3. 当前清单决定本次有哪些原文可用。旧数值快照内“原文未获取”的历史说明不否定当前已有文件；一份最新财报也不代表覆盖了所有公司或期间。
4. 如两类证据的数字不一致，先核对期间、单位、合并范围和重述版本，再说明差异。不要挑一个数字静默覆盖另一个。纯文档或纯数字任务本身不是“数据缺口”；只有回答所需的证据确实缺失时才列具体限制。

## 按问题选择分析维度

综合财务分析优先覆盖以下相关维度；聚焦问题只选择有帮助的维度，不机械凑章节。

- **增长与收入质量**：规模、同比/环比和多期趋势；季节性、产品/地域结构、价格/销量、汇率等驱动，仅在原文有证据时归因。不要只罗列变动百分比。
- **盈利能力**：毛利率、经营利润率、净利率及其变化；结合成本、费用、业务组合和一次性项目解释利润与收入是否同步。百分点变化与百分比变化分开表达。
- **现金流与利润兑现**：经营现金流、资本开支、自由现金流，现金与利润的背离；原文支持时讨论营运资本、收付款时点及非现金项目。单季波动不自动等于长期恶化。
- **资产负债与流动性**：现金、资产、负债和权益的变化；根据实际披露讨论债务期限、偿债与资金安排。现金及等价物不等于包含投资的全部流动资金；没有流动资产/负债、债务等证据时，不编造流动比率或净债务。
- **投资与资本配置**：资本开支、研发、收购、回购和分红等有依据的重大事项，判断与经营现金创造和未来投入的关系。区分事实与分析判断，避免无证据评价“激进”或“保守”。
- **驱动、风险与后续关注**：用管理层讨论和附注交叉解释数字，关注集中度、竞争、汇率、监管及会计估计等相关风险；区分本期新增风险和延续披露。不声称读完未实际检查的章节。

每个重要结论尽量回答：发生了什么 → 哪些数值支持 → 原文如何解释 → 有什么限制或值得跟踪的问题。证据不足时缩小结论强度，而非补写因果。

## 使用文件工具时节制上下文

- 先使用清单及规范化数值证据，避免反复加载包含完整来源快照的同一张表；确需公式/血缘时再读取对应表格。
- 针对问题搜索相关表格、MD&A 或附注，合并相近查找，保留必要上下文。原生 Read 对超长单行 HTML 可能截断；此时可用 Bash 做临时通用文本处理，而非反复读取同一截断片段。
- 不把完整 HTML 反复传回模型，也不将临时处理结果冒充原始文件。读取顺序及处理代码由你选择；不预设必须逐章通读。
- 有足够证据回答问题就停止研究。一次性整理关键数字、解释、引用和限制，交给最终报告阶段，不把完整工具输出重复进研究结论。

## 数值、引用与判断

- 使用已提供的确定性计算结果及其单元格引用。没有经过财务计算工具的临时脚本结果不能当作已验证结构化指标；必要时清楚标注原文数值或分析性算术，不能伪造单元格。
- 结构化数值结论用对应单元格引用；管理层解释、业务事实和风险用原文文档引用。混合证据报告根据实际论点使用两类引用，不用整篇文档引用替代已有的数值血缘。
- 区分四类内容：原始事实、算术推导、管理层明确陈述、分析判断。算术计算不是业务原因推断；管理层说法也不是独立验证后的因果结论。
- 保留真实缺失和冲突，使用财务语言说明影响；不输出内部字段名、工具协议或“numeric_cells 为空”等系统说明。

## 报告组织

默认先给一段核心结论，再按相关维度组织简洁分析，最后列关键限制及两三项后续关注。优先用少量关键数值和因果联系，不堆砌表格、长英文原句或逐地区重复句。

用户有字数要求时，优先满足该要求：短报告合并维度、删去次要信息，引用保留，不因为上述维度较多而扩写。没有指定时，以能清楚回答问题的篇幅为准。不要把“提供了哪些文件”的内部说明写成额外数据缺口；不要在同一报告重复通用免责声明。
